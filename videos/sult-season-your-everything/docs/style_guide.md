# Style guide: SULT motion concept

Source: ../../brand/SULT_BRAND_BRIEF.md §3 + the brand's own statics (brand/assets/infographics) + measured logo files.

| Token | Hex | Use |
|---|---|---|
| lime | #CDFF00 (logo file #D7FC00) | the ONE accent: highlight boxes, pills, marquee, wipes |
| teal | #00C3C8 | the product (sachets, boxes), the six-electrolyte scene |
| ink | #261E1E | logo, headlines, hook + proof grounds |
| stone | #E5E5EB | data / proof grounds |
| sky | #9FD3DA → #F2FAFB | product backdrop (their bottle + infographic shots) |
| flavours | WB #E58FC3 · PC #F4B49A · MT #F2D27A | flavour drops only |

Type: Libre Franklin 900, ALL CAPS, tight leading (Franklin Gothic stand-in per brief) · Chivo 400/700 for captions and data labels.
Motifs: lime highlighter boxes behind key words, pill labels, strikethrough marquee, typewriter cursor, flash-photo pops on portrait cuts (≤ 1 per second), slight camera shake on the hangover cut. Snappy springs, hard lime wipes on the beat, no soft corporate easing.
Photography: their flash-lit fruit-bite portraits and fisheye POV shots, used as-is (portraits upscaled 2×, shown as large cards).
